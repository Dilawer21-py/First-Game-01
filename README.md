# First-Game-01 🎮

This is my first Python game project, based on the classic **Rock, Paper, Scissors** game.

I created this project to practice my Python programming skills and understand how basic programming concepts work in a real project.

Through this game, I practiced:
- Taking user input.
- Using conditional statements (`if`, `elif`, `else`).
- Working with Python's `random` module.
- Comparing user and computer choices.
- Implementing basic game logic.
- Displaying results using `print()`.

This project is a small but important step in my Python learning journey. I will continue building more projects to improve my problem-solving and programming skills.

**Language:** Python 🐍

**Project:** Rock, Paper, Scissors
